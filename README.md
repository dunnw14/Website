# William Dunn — Portfolio Content Archive

This repo currently holds the captured copy/content from the [Base44](https://base44.com)
portfolio app ("Luminary Portfolio", live at `william-dunn-portfolio.base44.app`),
transcribed from screenshots into structured JSON. It's a content source of
truth to build a real site from later — no app/site has been built yet.

## Contents

- `content/home.json` — nav, hero copy, tag ticker, footer
- `content/case-studies.json` — case studies listing intro + full copy for all 7 case studies (overview, background/challenge, role & responsibilities, process & approach, key deliverables, impact & outcomes, reflection & learnings)
- `content/skills.json` — skills page copy, grouped by Service Design / CX Strategy / GenAI
- `content/cv.json` — CV page copy: profile, experience history, core capabilities, industry experience

## Notes

- Work sample images, case study illustrations, and embedded videos were
  intentionally **not** captured — text/copy only.
- Original source pages: Home (`/`), Case Studies (`/CaseStudies`), Case Study
  Detail (`/CaseStudyDetail`, one per case study), Skills (`/Skills`), CV (`/CV`).
